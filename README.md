#  Swiggy Sales & Delivery Analytics Dashboard

## 📊 Project Overview

The **Swiggy Sales & Delivery Analytics Dashboard** is an interactive business intelligence project developed using Microsoft Power BI. It transforms food delivery order data into meaningful visual insights to support analysis of revenue, delivery efficiency, customer satisfaction, and restaurant performance.

## 🎯 Key Features

* **Revenue Analysis:** Track average final amount and average order value.
* **Delivery Performance:** Monitor average delivery time to evaluate operational efficiency.
* **Customer Satisfaction:** Analyze customer ratings and restaurant ratings.
* **Order Status Analysis:** Visualize order distribution by status.
* **Dynamic Filtering:** Filter insights by order date and restaurant city, including Mumbai and Pune.
* **Interactive Visualizations:** Present key performance indicators (KPIs) and charts in a user-friendly dashboard.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Data Visualization
* Business Intelligence (BI)
* Data Analysis
* KPI Reporting

## 💡 Business Value

This dashboard helps identify sales trends, evaluate delivery performance, understand customer feedback, and monitor order outcomes. It demonstrates how interactive data visualization can turn raw food delivery data into actionable business insights.

## 👨‍💻 Project Objective

To demonstrate practical skills in data analysis, dashboard development, KPI monitoring, and business intelligence using a real-world food delivery analytics use case.
